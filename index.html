为什么分布函数一定带指数？

平衡态 + 三个方向平权，是整条推导的起点。

f(vx,vy,vz) = g(vx)g(vy)g(vz)
= A e−α(vx²+vy²+vz²)

① 平衡态下，速度的三个分量相互独立，联合分布等于三个一维分布的乘积；② 空间各向同性，分布只能依赖 v²（旋转坐标系不该改变结果）。

同时满足“乘积形式”与“只依赖平方和”的函数只有指数函数，于是每个分量都是高斯型：g(u) ∝ e−αu²。常数 α 暂时未知，下一步用温度把它定下来。

这一步没有涉及任何具体气体——指数形式是“独立 + 各向同性”的直接结果。

用温度确定 α

温度是分子平均动能的度量，它决定分布的“宽度”。

⟨vx²⟩ = 12α  ,  ⟨12mv²⟩ = 32kT
⇒   α = m2kT

标准高斯分布 e−αu² 的方差为 1/(2α)，所以每个方向 ⟨vx²⟩ = 1/(2α)。能量均分定理给出 ⟨½mv²⟩ = 3/2·kT，而 v² 有三个分量，代入即得 α = m/2kT。

质量 m 出现在分母：同样的温度下，越重的分子速度分布越窄；温度 T 出现在分子：越热，分布越宽。这与原图中“温度升高曲线变宽、质量增大曲线变窄”完全对应。

归一化常数 A

所有分子的概率加起来必须等于 1。

1 = A ∫ e−αv² d³v = A (π/α)3/2
⇒   A = (α/π)3/2 = (m/2πkT)3/2

这里用到标准积分 ∫−∞∞ e−αx²dx = √(π/α)。三个方向各贡献一个 √(π/α)，乘起来就是 (π/α)3/2。

至此，速度矢量在“速度空间”里的分布已经确定：f(vx,vy,vz) = (m/2πkT)3/2 e−mv²/2kT。但我们要的是速率 v 的分布，还需要把方向“积分掉”。

球壳：为什么多出一个 v²

速率相同、方向不同的速度矢量，落在一个球面上。

半径 v、厚度 dv 的球壳体积为 4πv²dv。速率从 v 到 v+dv 的分子，数量正比于这个球壳的体积。
f(v)dv = 4π (m/2πkT)3/2 v²
     × e−mv²/2kT dv

把速度空间分布乘以球壳体积，就得到速率分布。多出来的 v² 来自几何：速率越大，对应的球壳越大，能容纳的方向越多。这解释了曲线为什么从 0 开始上升，而不是在 v = 0 处最高。

峰值与三种特征速率

对 f(v) 求极值、求平均、求平方平均。

vp = 2kT/m
v̄ = 8kT/πm = 2√π vp ≈ 1.128 vp
vrms = 3kT/m = 3/2 vp ≈ 1.225 vp

最概然速率 vp：令 df/dv = 0。指数外的 v² 与指数内的 e−mv²/2kT 竞争，极值出现在 vp = √(2kT/m)。

平均速率 v̄：∫v f(v)dv = √(8kT/πm) = (2/√π)·vp ≈ 1.128 vp。

方均根速率 vrms：√⟨v²⟩ = √(3kT/m) ≈ 1.225 vp，它与平均动能直接对应：½m vrms² = 3/2·kT。

三者之比恒为 1 : 1.128 : 1.225，与温度、气体种类都无关。温度只让它们整体变大，质量只让它们整体变小。

曲线为什么长这样

两股力量相乘：几何让曲线上升，能量让曲线下降。

几何因子 v² 能量因子 e−mv²/2kT 两者乘积 f(v)

低速端：e−mv²/2kT 接近 1，v² 很小，所以曲线从 0 缓慢上升；高速端：v² 继续增大，但指数因子迅速衰减，最终压倒 v²，曲线出现一条很长的右侧拖尾。

这条拖尾不是数学细节，而是很多真实现象的来源：蒸发、化学反应、大气逃逸，都只靠尾部那一小撮高速分子。

04 · 三种特征速率

同一条曲线，三个“代表值”

它们都正比于 √(T/M)，但系数不同。下面的数值与上方实验实时联动，可以边改温度边比较。

Most probable

最概然速率 vₚ

vp = √(2kT/m)
422m/s

曲线最高点对应的速率，出现概率最大。

Mean

平均速率 v̄

v̄ = √(8kT/πm) = 2vp/√π
476m/s

所有分子速率的算术平均，比 vₚ 大约 12.8%。

RMS

方均根速率 vrms

vrms = √(3kT/m)
517m/s

平方再平均再开方，与平均动能直接对应，三者中最大。

vₚ : v̄ : vrms = 1 : 1.128 : 1.225 这个比例是常数，与温度、质量都无关。温度升高时三者一起增大（曲线右移、变宽、峰值降低）；分子变重时三者一起减小（曲线左移、变窄、峰值升高）。

05 · 从曲线到真实世界

那条向右拖尾的曲线，解释了很多事

原图停在“温度与质量的影响”。再往前一步：分布的高速率尾部决定了哪些分子能蒸发、反应、逃逸，也决定了同位素分离为什么如此困难。

01 / EVAPORATION

蒸发与沸腾

只有速率足够大的分子才能挣脱液面。温度升高时，高速尾部占比快速增加，蒸发随之加快；留下的分子平均速率更低，所以蒸发会降温。占比虽小，但分子碰撞极其频繁，宏观蒸发仍然明显。

02 / ISOTOPE

同位素分离

²³⁵UF₆ 与 ²³⁸UF₆ 的平均速率只差约 0.43%。两条分布几乎完全重合，所以气体扩散法必须把成千上万级串联起来，才能一点点放大差异。

²³⁵UF₆²³⁸UF₆右侧为峰位放大
03 / ATMOSPHERE

大气逃逸

氢和氦质量小、高速尾部占比大，更容易达到逃逸速度。地球大气中几乎没有游离的 H₂ 和 He，而质量更大的 N₂、O₂ 留了下来。

04 / REACTION

化学反应速率

只有能量超过活化能的分子才能发生反应。温度略升，尾部占比按指数增长，这就是 Arrhenius 公式中反应速率对温度极其敏感的原因。

05 / LOW TEMPERATURE

低温物理

vₚ ∝ √T。温度降到 50 K，分布整体左移、变窄，分子速率变得非常集中。激光冷却、稀薄气体实验都工作在这样的区间。

06 / BIG PICTURE

统计力学的入口

麦克斯韦分布只处理平动速率；把同样的思路推广到能量，就得到玻尔兹曼分布。它把微观的随机运动，与宏观的温度、压强、反应速率连接起来。
